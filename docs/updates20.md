# 20 次更新路线图

## 验证约定

- 每次更新至少跑一次 `--selftest`，涉及 UI/战斗的加一条自检。
- 每个版本节点跑 `--smoke`、导出 Windows + Android，真机安装截图。
- 更新记录写入 `docs/devlog.md` / `CHANGELOG.md`，并同步 workspace `docs/流程记录.md`。
