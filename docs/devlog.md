# 开发日志

## v2.2.0 — 2026-10-30

### 内容

- **鼠标职责重排**：左键 = 挥镰 / 收获成熟作物；右键 = 点地移动 / 松土 / 播种 / 浇水。右键点到成熟作物会提示「用左键收获」。
- **白天偷菜海鸥**：每 16–23 秒从岛边刷一只「偷菜海鸥」，会飞向作物啃食；左键砍掉得 3 金，横幅提示。
- **沙滩采集**：每 5.5–8.5 秒刷贝壳/海星，走过去捡 2–4 金，30% 概率额外得 1 颗随机种子，最多同时 3 个。
- **提前收工**：`R` 或 HUD「结束白天」按钮直接进夜晚；已浇水作物按剩余白天时间结算生长（`Crop.advance`），不浪费等待。
- HUD 底部提示、标题操作说明、暂停说明同步新映射。

### 验证记录

- `--selftest`：**82/82 PASS**（左键挥镰、右键移动、贝壳拾取、海鸥生成、Crop.advance、跳过白天进夜晚）。
- 截图：`shot_daylife.png`（海鸥 + 贝壳 + 结束白天按钮）、`shot_mouse.png`（左键收获提示）。
- 版本 2.2.0，Android versionCode 10。

### 工程备注

- Godot 在本机无法写 `%APPDATA%`（安全管理软件拦截），所以存档改为 exe/项目旁边；导出时用 `TEMP` 指向工作区目录。
- 字体使用 Cubic 11（OFL），已验证 GB2312 常用字覆盖。
- 音乐是 numpy 合成后写 WAV，Godot 侧设置 `LOOP_FORWARD` 循环。
